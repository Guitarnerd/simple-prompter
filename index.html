    Simple Prompter

    A teleprompter that reads your scripts from Google Docs and keeps them on this device, so a recording still works when the Wi-Fi doesn't.

    Put it on your home screen

    Already installed on this device.

    Installing opens it full-screen, like any other app.

    1. Open this page in Safari.
    2. Tap the Share button in the toolbar.
    3. Scroll down and tap Add to Home Screen, then Add.
    4. Open Prompter from the home screen.
    1. Android (Chrome): tap the ⋮ menu, then Add to Home screen or Install app.
    2. Windows or Mac (Chrome, Edge): click the install icon at the right end of the address bar.

    Remote setup

    Pair the remote with this device over Bluetooth, then press any button on it. If a key name shows up below, the app can hear it. To change what a button does, tap an action's Assign button, then press the remote button.
